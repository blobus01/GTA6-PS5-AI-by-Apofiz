# GTA 6 (PS5): транспорт, шпаргалка

Схема управления по умолчанию: Default. Есть ещё Classic и Left-Handed (Settings > Control Scheme). В Default спринт пешком на L3, а не на Cross.
Пометка "(unverified)" значит, что пункт взят из одного слабого источника или источники расходятся.

## Общее для любого транспорта
- Правый стик: камера. **R3 (удержать)**: смотреть назад.
- **R1**: стрельба из транспорта (не R2!). L1: убрать оружие. **L1 (удержать)**: выбор оружия / loadout.
- **D-pad вниз (тап)**: цель / миникарта. **D-pad вниз (удержать)**: Quick Navigation (время замедляется, можно отметить ближайшее место, например заправку, и получить GPS).
- **D-pad вправо (удержать)**: меню напарника. С R1: смена персонажа.
- **D-pad вверх (тап)**: телефон. **D-pad вверх (удержать)**: Interact / WAiNK-сканер.
- Тачпад: карта. Options: пауза.
- L3+R3: Focus.

## Машины, мотоциклы, лодки (общая раскладка)
| Кнопка | Действие |
|---|---|
| Левый стик | Руль |
| R2 / L2 | Газ / тормоз, задний ход |
| **Cross** | Ручник. Держать в повороте на скорости: дрифт или разворот |
| **L3 (клик)** | Сигнал / нитро (нитро только если стоит Boost-апгрейд) |
| Circle (тап) | Фары (Shacknews). У GTABase фары в меню машины (unverified) |
| **Circle (удержать)** | Пригнуться, спрятаться от копов |
| D-pad влево / вправо (тап) | Поворотники |
| **D-pad влево (удержать)** | Меню машины (выбор правым стиком): радио, фары, окна, багажник, аварийка, глушить/заводить двигатель |
| Square | Удар дверью / пинок (мото, скутеры) |
| R1 без оружия | Средний палец. **R3 (клик)**: наорать на прохожих и водителей |
| **Triangle** | Выйти. **Удержать**: остановиться и выйти. **Двойной тап**: выпрыгнуть на ходу, двигатель остаётся заведённым, машина катится дальше |

- **Стрельба из машины:** наводиться камерой (правый стик), стрелять R1. Персонаж высовывается по пояс, можно и с винтовкой. Есть ли отдельный прицел на L1, источники расходятся (unverified).
- **Вид от первого лица:** только с телефоном в руках (D-pad вверх). Свободной камеры из салона нет (games.gg).
- **Кинокамера и автопилот (Auto-Drive):**
  1. Поставить точку на карте.
  2. Держать D-pad вниз (Quick Navigation) и, не отпуская, нажать **Options**. Включится кинокамера.
  3. Удерживать **Circle**, чтобы включить Auto-Drive. Если подсказка не появилась, чуть газануть R2.
  4. L2 / R2 меняют скорость. Удержание D-pad вниз возвращает обычный вид.
  - Автопилот соблюдает ПДД. Работает и на лодках, если до точки можно доплыть.
- **Не нашёл в источниках:** ремень безопасности, складная крыша (в мод-шопе есть только «Roof» в Bodywork), гидравлика.

## Мотоциклы
- Те же кнопки, что у машин. Левый стик: наклон.
- **Вилли:** левый стик назад, на газу. **Стоппи:** резко тормозить, стик вперёд. За трюки дают бонус, но если держать слишком долго, будет падение (unverified: GTABites, обрывок GTABase).

## Велосипеды
| Кнопка | Действие |

| L2 | Тормоз / назад |
| Левый стик | Руль / наклон |
| **Cross** | Спринт (на велике Cross по-прежнему) |
| **Circle** | Банни-хоп |
| L3 | Звонок |
| Square | Пинок |
| Triangle | Слезть |

## Лодки, гидроциклы, аэроботы
- Раскладка как у машин (R2 газ, L2 тормоз/назад, левый стик руль).
- Лодку или гидроцикл можно столкнуть с песка в воду, малую лодку можно столкнуть с прицепа (как толкать машину, см. ниже).
- Машины тянут прицепы с лодками / гидроциклами через фаркоп (Dexerto, по трейлерам).
- Аэроботы, свомп-багги, квадроциклы, монстр-траки и каяки есть в игре, но отдельных кнопок источники не дают.

## Самолёты
| Кнопка | Действие |
|---|---|
| R2 / L2 | Тяга больше / меньше |
| Левый стик | Тангаж / крен |
| Square / Circle | Рыскание (руль направления) влево / вправо |
| **L3 (клик)** | Шасси |
| D-pad влево | Радио. Удержать: меню транспорта |
| L1 (удержать) | Оружие (только у вооружённых) |
| Triangle | Выйти |

- **Гидроплан** (миссия гл.1 «Gone Fishing»): держать R2, стиком поднять нос, рулить Square/Circle (работает и в воздухе, и на воде).
- **Посадка на воду:** снизиться над открытой водой и отпустить R2. Машина сядет сама, сел, когда высота около 6 ft. Мангры и деревья цепляются легко.
- Если управление кажется инвертированным: Settings > Controller > Inverted Controls > Aircraft Movement.

## Вертолёты
- **R2**: набор высоты. **L2**: снижение. **Square / Circle**: поворот влево / вправо.
- Наклон и движение левым стиком, как в GTA 5 (unverified, отдельно для GTA 6 не подтверждено).
- Висение и посадка: выровнять машину и плавно снижаться на L2 (совет из GTA 5, unverified).

## Парашют
- Cross: раскрыть. Левый стик: поворот.
- L2 / R2: тормоз левой / правой стропой.
- Triangle: отстегнуть. R1: стрелять. D-pad вверх (удержать): WAiNK.

## Поезда
- Поезда в мире есть. Можно ли ими управлять, не подтверждено (unverified).

## Угон
**Сканируй WAiNK** (D-pad вверх, удержать, на машину). Карточка показывает:
- доступ: Unlocked / Locked / Key Cloner / Registered;
- охрану: Alarmed / Deactivated;
- трекер: None / Standard / Advanced;
- цену продажи, стоимость регистрации, состояние кузова, нужна ли машина Мозесу.

| Способ | Как | Когда доступно |
|---|---|---|
| Выкинуть водителя | Подойти к занятой машине, например на светофоре. Трекер остаётся | С начала |
| **Разбить стекло** | **Circle**. Мгновенно, но громко: сработает сигнализация, упадёт цена | С начала |
| **Хотвайр** | В водительском кресле свести **левый и правый стики** в нужные точки, чтобы заполнить полукруги L и R. Обучение в миссии «Unwanted Attention» (Imponte '77 Phoenix) | С начала, но не у всех машин |
| **Slim Jim** | **Triangle** у запертой машины, выбрать Slim Jim, **вращать правый стик**, пока не заполнится розовая шкала и не щёлкнет замок. Тихо, без повреждений, но медленно, ты на виду. Внутри всё равно нужен хотвайр | Гл.2, миссия у Мозеса (Watkins Auto Parts / Pay 'n' Spray) |
| **Key Cloner** | Телефон: Settings > Install key_cloner_v1.6.9 (ставится на обоих героев). У двери выбрать Key Cloner, двигать стик в нужную сторону, когда индикатор розовый. Заводить сразу, без хотвайра | Гл.3, «Steal the Zorrusso for Randy» (Clonin' Keys, Makin' G's), около 40 ч игры |

- **Keyless** (бесключевые) машины можно вскрыть стеклом, но без клонера не завести. Если нет пазла зажигания, это не баг.
- **Трекеры.** Advanced: красная иконка у индикаторов двигателя и топлива. Если долго едешь медленно, копы автоматически получают твою позицию. Снятие трекера открывается позже и стоит дорого.
- Номера остаются, угнанную машину можно опознать. Опознанную копы увозят на штрафстоянку (оттуда её можно угнать обратно).
- **Чистый уход:** заехать в многоуровневый паркинг, надеть маску, пересесть в неприметную машину, сжечь горячую молотовым. Без погони можно просто припарковать и уйти.

## Продажа, регистрация, гаражи
- **Мозес** (гл.2): берёт только нужные ему машины без трекера. Цена зависит от состояния.
- **Pay 'n' Spray** (с «Welcome to Vice City», начало гл.3): берут машины без трекера и со Standard, примерно $2.5–4k+. Есть дневной лимит.
- **Randy** (Leonida Auto World, середина гл.3): Wish List из 18 суперкаров по $30k+ за идеальное состояние, трекер не важен. Повреждения режут цену.
- **Регистрация** (смена номеров): у Мозеса для машин без трекера, с гл.3 в Pay 'n' Spray (без трекера и со Standard). Незарегистрированная машина пропадает при перезагрузке.
- Незарегистрированную можно временно держать в гараже или мотеле. Не тюнингуй её до регистрации, деньги на моды могут сгореть.
- **Scooter Bros** (приложение): доставить свою машину, починить, забрать со штрафстоянки, переименовать. Цена: база $100 плюс ремонт и расстояние. Premium за $12,500 даёт 3 бесплатных использования в день. Во время погони недоступно.

## Ремонт, топливо, тюнинг
- **Топливо и здоровье двигателя.** Пустой бак или убитый мотор, и машина не едет.
- Ремонт:
  - заправка: мелкий ремонт и бензин, дешевле Scooter Bros;
  - Pay 'n' Spray: ремонт и перекраска, перекраска сбрасывает узнаваемость для копов;
  - мод-шоп: полный ремонт;
  - звонок механику Joey: доступен после миссии «Just A Scratch».
- **Мод-шопы:** 14 штук, у каждого своя специализация, не каждый работает с любой машиной. Первый: Coastal Auto Care (Keys).
  - L1 / R1 листают вкладки.
  - Перед тюнингом машину нужно починить.
  - Нитро и турбо стоят в Performance > Boost, не на всех машинах.
- **Перевернулась машина:** подойти сбоку, L3 (стойка «толкать»), держать **Square**. Не сработает, если машина тяжёлая, кончилась стамина или крутой склон. Так же можно толкать машину без бензина.

## Про-советы
- Улицы уже, трафика больше. Тормози до поворота, газуй на выходе. Грузовики и SUV требуют больше дистанции.
- Начинать лучше со старых машин без трекера. Суперкары почти всегда с Advanced-трекером.
- Держи сменную одежду в багажнике своей машины: переодевание помогает сбросить внимание копов.
- На 1 звезде можно договориться: убрать оружие, L2 на копа, выбрать «defuse».
