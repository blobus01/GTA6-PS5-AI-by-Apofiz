# Правила нарезки шортсов из геймплея бота
Источник: Try CGI (Паша), «Claude нарезал стримы GTA 6 за меня» youtube.com/watch?v=hyQ9k-YJbDQ, 22.11.2026. Изучено по просьбе Рината 26.11 для проекта GTA6 PS5 AI .

**Правила клипа:**
- Хук в первые 1.5–2 с (зритель решает за ~1.5 с). Без вступлений и объяснений «что сейчас будет»; нужен контекст — короткий текст-оверлей.
- Длина 20–40 с (макс 45): досмотры = главный сигнал алгоритма.
- Начало — хук, конец — панчлайн. Лучшие моменты: крик, смех, фейл, игровая ситуация, спор с чатом; громкость и слова совпадают.
- Скоринг каждого кандидата: эмоция в первые 2 с? понятно без контекста? хочется переслать другу?
- Стиль: вертикаль 9:16, вебка сверху / геймплей снизу, пословные субтитры, большой хук-текст в первые 2 с.
- Пайплайн Claude: транскрипт со таймкодами → пики громкости (крики, смех, удары) → синхрон со словами/вопросами → выбор лучших → нарезка → сначала 1–2 пробных, после «ок» — остальные. Бриф = 3 MD-файла: «Правила», «Стиль», «Монтаж» (шаги, проверка, что сдать).
- Подпись: 1-я строка хук, ник стримера, хэштеги, обязательный текст кампании/стримера.

**Публикация и деньги:** один клип сразу в TikTok+Shorts+Reels; 3–5 клипов/день на аккаунт (больше — риск); отдельный аккаунт на стримера; не удалять «залипшие» — могут выстрелить через неделю–месяц. Запад: Whop Content Rewards ≈ $1 за 1000 просмотров (~$1000/млн), обязательно отправить ссылку в кампанию. СНГ: 7–12 тыс ₽/млн, договариваться напрямую (3–5 пробных клипов → письмо стримеру).

**Запреты/грабли:** чужой стрим без разрешения → страйки (3 = бан канала); фоновая музыка → копирайт-блок, брать моменты без трека; шаблонные одинаковые ролики YouTube не монетизирует — свой хук/субтитры/стиль, менять оформление; TikTok сам почти не платит; маркировка рекламы/ник/партнёрство; казино-реклама — не трогать; накрутка = вечный бан; платят только за одобренные клипы по условиям кампании — читать условия ДО первого клипа.

**How to apply:** для шортсов из нашего бота GTA6 (свой геймплей — прав нет проблем) брать всплески (погоня, перестрелка, розыск, фейл, угон) с хуком в первые 2 с, 20–40 с, вертикаль, пословные субтитры, оверлей «мысли бота», брендинг Apofiz.
