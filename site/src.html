Перед стартом: разреши это на PS5Before you start: allow these on your PS5

Четыре настройки на самой консоли. Без любой из них приложение не подключится — проверь заранее, это 2 минуты с геймпадом.Four settings on the console itself. Miss any one and the app can't connect — check them first, it's two minutes with the controller.

1

Включи Remote PlayEnable Remote Play

Настройки › Система › Дистанционное воспроизведениеSettings › System › Remote Play
Включить дистанционное воспроизведениеEnable Remote Play

Главный переключатель. Выключен — консоль просто не отвечает приложению.The master switch. If it's off, the console simply ignores the app.

2

Режим покоя: оставайся на связиRest mode: stay connected

Система › Экономия энергии › Функции в режиме покояSystem › Power Saving › Features in Rest Mode
Оставаться подключённым к интернетуStay Connected to the Internet
Разрешить включение PS5 через сетьEnable Turning On PS5 from Network

Тогда бот сам будит консоль из режима покоя — не нужно подходить к ней.Then the bot wakes the console from rest mode itself — no need to walk over.

3

Тот же аккаунт PSNThe same PSN account

Пользователи и учётные записи › ДругоеUsers and Accounts › Other
AВошёл тот же PSN, что в приложенииSame PSN as in the app, signed in
Remote Play разрешён этому пользователюRemote Play allowed for this user

На PS5 должен быть тот же пользователь, под которым ты входишь в приложение, и ему разрешён Remote Play (у семейных и детских аккаунтов — в родительском контроле). Иначе — ошибкаThe PS5 must have the same user you sign in with in the app, and that user must be allowed Remote Play (for family and child accounts — in parental controls). Otherwise you get error 0x80108b12

1

Включи Remote Play на PS5Enable Remote Play on the PS5

Настройки → Система → Дистанционное воспроизведение → Включить. В «Энергосбережении» разреши включение по сети — тогда бот сам будит консоль.Settings → System → Remote Play → On. Under Power Saving allow turning on from the network so the bot can wake the console.

2

Скачай проектGet the code

git clone https://github.com/blobus01/GTA6-PS5-AI-by-Apofiz.git
cd GTA6-PS5-AI-by-Apofiz

Поставь зависимостиInstall dependencies

python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt ultralytics

YOLO11 (6 МБ) скачается сам при первом запуске.YOLO11 weights (6 MB) download on first run.

4

Собери мост к консолиBuild the console bridge

.venv/bin/python tools/build_native.py   # → native/libps5bridge.dylib

Уже собранная библиотека для Apple Silicon лежит в репозитории — шаг можно пропустить.A prebuilt Apple Silicon library ships in the repo — you can skip this.

5

Укажи IP консоли и запусти серверSet the console IP and start the server

cp .env.schema .env.local      # PS5_HOST=192.168.x.x
./start.sh                     # → http://127.0.0.1:8765
6

Привяжи консольLink the console

Открой http://127.0.0.1:8765 → войди в PSN → на PS5: Настройки → Система → Дистанционное воспроизведение → Связать устройство → введи 8-значный код. Делается один раз, ключи хранятся только у тебя в ~/.ps5-remote/.Open http://127.0.0.1:8765 → sign in to PSN → on the PS5: Settings → System → Remote Play → Link Device → enter the 8-digit code. One time only; keys stay on your Mac in ~/.ps5-remote/.

Подключи мозг и запусти ботаConnect the brain and run the bot

npm i -g @anthropic-ai/claude-code && claude   # sign in once

Картинка сыпется или замираетVideo breaks up or freezes

Это Wi-Fi. Подключи Мак кабелем или поставь рядом с роутером.That's Wi-Fi. Plug the Mac in with a cable or move it next to the router.

«Remote Play уже используется»"Remote Play already in use"

Закрой другие клиенты Remote Play, подожди ~8 секунд и подключись снова.Close other Remote Play apps, wait ~8 seconds, connect again.

Машина не заводитсяThe car won't start

Подсказка Clone Key — машина без ключа, нужен клонер из главы 3. Бот сам бросит её и найдёт другую.A Clone Key prompt means keyless — you need the cloner from chapter 3. The bot drops it and finds another.
